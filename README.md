# Moderni Herodot

Moderna digitalna enciklopedija povijesti — od prapovijesti do modernog doba.

## Opis projekta
Ovaj projekt je edukativna web stranica koja pokriva povijest različitih epoha, uključujući:
- Prapovijest
- Antička Grčka
- Srednji vijek
- Industrijska revolucija

Stranica sadrži tekstove, slike i osnovni stil putem CSS-a.

## Struktura projekta
- `index.html` – glavna stranica
- `style.css` – stilovi stranice
- `epohe/` – HTML datoteke za pojedine epohe
- `slike/` – slike koje se koriste na stranici
